Printable Threads for Autodesk Fusion

Close Fusion before installing. This installer copies the add-in for your user
account. No separate Python installation is needed. Existing add-in files are
backed up; your saved tool settings and Fusion designs remain unchanged.

This installer is digitally signed. Obtain it from the ealitt/PrintableThreads
GitHub release. Windows can still show a reputation warning for a new release.
